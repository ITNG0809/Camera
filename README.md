# SilentCam

ブラウザで動作するカメラアプリの初期実装です。

## 起動方法
カメラAPIはHTTPSまたはlocalhostでのみ利用できます。
- GitHub PagesなどHTTPSで公開する
- またはローカル開発サーバーで開く（localhost）

`index.html` を直接 `file://`  で開く方法ではカメラが利用できないブラウザがあります。

## 実装済み
- カメラ起動・停止、前面/背面切替
- 解像度の希望値指定（端末が対応しない場合は標準設定へフォールバック）
- 対応端末でのハードウェアズーム
- 明るさ（プレビューと保存画像）
- 3×3グリッド
- 3/5/10秒タイマー
- JPEG/PNG撮影、IndexedDB保存
- 写真一覧、プレビュー、複数選択、削除、ダウンロード

## 制限・注意
- ブラウザの仕様上、端末/OSが鳴らすシャッター音をWebアプリから無効化できる保証はありません。
- ズームはカメラの `getCapabilities()` が対応を返す端末のみ利用できます。
- 明るさは画像処理による調整です。カメラの露出補正そのものではありません。
- IndexedDBのデータはブラウザのサイトデータ消去や容量制限で失われる場合があります。大切な写真は端末へダウンロードしてください。
- 解像度は希望値であり、実際の解像度はカメラ/ブラウザが選択した値になります。
- 動作確認はコード構造・構文の初期チェックまでです。実機カメラの許可、ズーム対応、端末ごとの撮影音は実機で確認してください。

## ファイル構成
- `index.html`
- `css/`: UIスタイル
- `js/`: カメラ、撮影、写真保存、ギャラリー、設定
